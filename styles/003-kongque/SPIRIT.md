# 孔雀 / Peacock · 神意形

> Style #003 · 显影自一组经八个固定题材一致性验证的源图 · PLATE 003（8/8）
> 状态: v0-draft · 出生证见 [provenance/](provenance/)

## 神｜一句话

孔雀蓝釉色的赛璐璐世界——一整缸艳青里的墨与朱。

命名取「孔雀蓝釉」：陶瓷史上那种艳得发亮的青。这个世界不发生在纸上，发生在赛璐璐片上——干净、饱和、通透，像九十年代动画电影的一帧定格。

## 意｜五条原则

1. **青是世界的底，不是颜色之一。** 孔雀青 #00A9B1 铺满一切背景——天空、墙、桌面、海。它不是被选用的色，它是这个世界的物理。
2. **四元宇宙：青、墨、白、朱。** 黑色体块压住画面（人物的制服、树的剪影），白色提亮（鸽、云、玻璃），朱红是情绪色场——第五种色相不存在。
3. **朱红是色场，不是标点。** 与油印的 2% 红相反：这里的红可以铺满 30% 画面，作整段情绪的底（实测 2–28%）。
4. **干净即质感。** 赛璐璐没有噪点、没有做旧、没有颗粒——它的美在于平涂的纯度和描线的利落。web 面因此是三个风格里唯一零噪点的。
5. **字是招牌。** 文字以竖排红底白字的招牌形式进入画面（street_scene 实测），或以黑重标题压在青场上——字是场景里的物件，不是浮在上面的 UI。

## 形｜关键手法

- 全部 token → [style.json](style.json)；图像面 → [prompt-face.md](prompt-face.md)；排版面 → article-face.css
- 黑色体块锚定构图；细节靠线，体量靠块
- 竖排红招牌 motif：排版面的身份标记（writing-mode: vertical-rl）
- 暗色模式有实测依据：landscape/still_life 本就是夜景，夜青底 #061718 是组级实测色——**这是三个风格里唯一"暗档实测"的**。
- 青场上的字恒为墨（text-on-ink=#131A1B 两主题不变）：赛璐璐的字是描上去的，不是印反白。

## 血统声明

九十年代至千禧年的日式动画海报 × 孔雀蓝釉的陶瓷色谱。与前两席构成三角：油印是复制品的世界（单墨+缺陷），水粉是颜料的世界（多声部+纸牙），孔雀是赛璐璐的世界（四元+干净）。三席已把矩阵的谱系拉开：同一座图库，三种材料文明。
