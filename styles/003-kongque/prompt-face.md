# 孔雀 / Peacock · 图像生成面（Prompt 编译器）

把任意主题编译成「孔雀」风格的图像生成 prompt 并出图。量化值来自 PLATE 003 源图组实测（见 provenance/notes.md）。

## 编译规则（九问）

1. **画布**：竖幅 2:3；整幅以孔雀青 #00A9B1 作世界底色（天空/墙面/桌面皆青）。
2. **注意力几何**：主体占 30–70%，以黑色体块锚定；留白 5–25%（青场本身就是呼吸）。
3. **图像锚**：把主题转译成赛璐璐场景——人物、动物、器物、建筑均可，但必须有墨块压场。
4. **锚的媒介化**：cel 平涂上色，细节靠描线，体量靠色块；无渐变无照片质感。
5. **光**：白色即光——鸽、云、玻璃、白发、白瓷；不用光晕不用霓虹。
6. **色彩逻辑**：四元宇宙——青 #00A9B1 / 墨（近黑）/ 鸽白 / 朱红 #D40704。朱红是情绪色场，可铺 2–30% 画面；第五色相禁入。
7. **字（可选）**：竖排红底白字招牌一条，或黑重标题压青场；字是场景物件。
8. **情绪温度**：九十年代动画电影定格；安静的艳丽；少年气的疏离。
9. **硬性禁项**：第五色相、渐变、光泽、3D、景深、霓虹灯效、噪点做旧、照片质感。

## 变体轴（每次各选一项；连续输出必须换轴）

| 轴 | 选项 |
|---|---|
| 布局族 | 人物特写式 / 场景全景式 / 静物台面式 / 仰视天空式 |
| 朱红权重 | 色场级（15-30%）/ 点缀级（2-8%）/ 无红 |
| 时刻 | 白昼青 / 夜青（#061718 底，实测有据） |
| 招牌字 | 竖排红招牌 / 无字 |
| 白的载体 | 鸽群 / 云 / 玻璃器 / 白发人物 |

## Prompt 骨架（四段紧凑体）

1. 青场世界底+画幅
2. 主体+墨块锚定+描线细节
3. 四元配色（写明朱红权重与 hex）+白的载体
4. 动画定格情绪+禁项清单

基底片段：见 style.json `prompt_fragment`。

## 质量门（出图后自检，不过即重生成一次）

- [ ] 背景是否整幅孔雀青（或夜青）？
- [ ] 只有青/墨/白/朱四元？无紫黄橙？
- [ ] 有黑色体块压场？
- [ ] 朱红若出现，是色场或明确点缀（非杂色）？
- [ ] 干净平涂——无噪点/渐变/照片质感/霓虹？
