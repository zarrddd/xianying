# 水粉 / Gouache · 图像生成面（Prompt 编译器）

把任意主题编译成「水粉」风格的图像生成 prompt 并出图。量化值来自 PLATE 002 源图组实测（见 provenance/notes.md）。

## 编译规则（九问）

1. **画布**：竖幅 2:3 或 3:4；奶油纸底（#F0EBE1 感）可见纸牙；哑光颜料质感。
2. **注意力几何**：留白 10–30%（天空或墙面的单色场）；主体占 25–50%。
3. **图像锚**：把主题转译成可平涂的形——人物、建筑、植物、器物、动物剪影级色块。
4. **锚的媒介化**：不透明水粉平涂，无描边，无笔触炫技；细节靠形状分割不靠线条。
5. **光**：正午平涂光——影子是干脆的实色形状，无渐变无羽化。
6. **色彩逻辑**：四主声部——砖红 #B93F49、深松绿 #2B5351、海蓝 #427E98、粉墙 #EBAEAB，奶油纸底统一；阳光黄 #E2C15A 只做 ≤2% 点睛；**无黑**（最深用松墨）。
7. **质感**：纸牙颗粒、平涂边缘轻微不匀、微透底——写生感，不是印刷感。
8. **情绪温度**：假日的、正午的、地中海的；明快而安稳。
9. **硬性禁项**：描边/线稿、黑色、渐变、光泽、3D、景深、霓虹、照片质感、脏灰。

## 变体轴（每次各选一项；连续输出必须换轴）

| 轴 | 选项 |
|---|---|
| 布局族 | 主体特写式 / 全景场景式 / 静物台面式 / 门窗框景式 |
| 光位 | 顶光正午影 / 侧光长影 / 无影平光 |
| 声部权重 | 红主唱 / 绿主唱 / 蓝主唱（其余声部退和声） |
| 黄点 | 有（≤2% 点睛）/ 无 |
| 呼吸场 | 天空 / 墙面 / 台面单色场 |

## Prompt 骨架（四段紧凑体）

1. 画布+纸牙+哑光颜料
2. 主体形状+平涂处理+占比
3. 四声部配色（写明主唱声部与 hex）+平涂影
4. 假日情绪+禁项清单

基底片段：见 style.json `prompt_fragment`。

## 质量门（出图后自检，不过即重生成一次）

- [ ] 无任何描边/轮廓线？
- [ ] 无纯黑？最深色仍是松绿/酒红族？

- [ ] 留白 10–30%，主体 25–50%？
- [ ] 纸牙/哑光在场，无照片质感与光泽？
