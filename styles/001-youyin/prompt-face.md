# 油印 / Mimeo · 图像生成面（Prompt 编译器）

把任意主题/句子/物件/情绪/文章立意，编译成「油印」风格的图像生成 prompt 并出图。
范式脉络：prompt-compiler 派（散文规则 + 量化约束 + 变体轴 + 质量门）；所有规则文本为本项目原创，量化值来自 PLATE 001 源图组的实测（见 provenance/notes.md）。

## 编译规则（九问）

1. **画布**：竖幅 2:3，满幅出血；暖纸底（#EDEBE1 感），平面扫描视感；无边框、无 mockup、无投影。
2. **注意力几何**：留白 0–15%。一个主导主体占画面 30–60%，其余空间由拼贴块填满（网点照片块 / 墨色色块 / 报纸微文字栏）。
3. **图像锚**：把主题转译成一个可印刷的主体——人物头像、动物头部、器物、树影、房子、街景人流。主体必须在缩略图尺寸一眼可辨。
4. **锚的印刷化**：三选一——solid-posterize（极端两档实色）/ halftone（网点照片）/ duotone（蓝黑双档套印）。禁止干净原图。
5. **文字系统**：可选一个超大 grotesque display 单词，裁切出血、宁读一半；报纸微文字栏当纹理（不必可读）；小号打字机标签（日期/编号）可点缀。
6. **色彩逻辑**：单墨世界——钴蓝 #21418C 家族 + 纸白 + 墨黑。可选珊瑚红 #E2767E 标点一处，面积 ≤2%，只落在墨场/图像上，不落裸纸。禁第二色相、禁彩虹。
7. **复制质感**：丝网/risograph 颗粒、轻微错版、撕边或硬裁边、复印损耗；平光、低反差纸面，无硬阴影。
8. **情绪温度**：档案的、街头的、九十年代的；喧哗但有秩序；punk-adjacent 但克制。
9. **硬性禁项**：渐变、光泽、3D、景深、霓虹、干净摄影、大留白极简、圆角卡片 UI、emoji、多色。

## 变体轴（每次生成前各选一项；连续输出必须换轴）

| 轴 | 选项 |
|---|---|
| 布局族 | 中心主体式 / 满幅场景式 / 竖条堆叠式 / 网格瓦片式 |
| 主体处理 | solid-posterize / halftone photo / duotone 套印 |
| display 大字 | 有（裁切出血）/ 无 / 残词碎片 |
| 红标点 | 有（≤2%）/ 无 |
| 微文字密度 | 高（织物级）/ 低（点缀级）|

## Prompt 骨架（四段紧凑体）

1. 画布+纸底+密度几何（主体占比、留白上限）
2. 主体隐喻+印刷化处理方式
3. 文字行为+单墨色彩逻辑（写明 #21418C 与红标点开关）
4. 复制质感+平面扫描感+禁项清单

基底片段（可直接并入）：见 style.json `prompt_fragment`。

## 质量门（出图后自检，不过即重生成一次）

- [ ] 留白 ≤15%？主体占 30–60% 且缩略图可辨？
- [ ] 全图只有一种彩色色相（蓝）？红若出现是否 ≤2% 且不在裸纸上？
- [ ] 所有图像元素都有印刷化处理（网点/posterize/错版任一）？
- [ ] display 字是否裁切出血而非完整居中标题？
- [ ] 无渐变/光泽/3D/干净照片/大留白？
