## 神｜一句话

一缸蓝墨水里冲洗出来的九十年代街头记忆——复印机时代的档案感。

它不怀旧于某个题材，而怀旧于一种**复制技术**：丝网、油印、影印。画面里没有"现实"，只有被印过一遍的现实。

## 意｜五条原则

1. **一缸墨。** 整个世界只有一种墨——钴蓝（#21418C）。黑是墨的浓，灰是墨的网点，白是纸的裸。第二色相（珊瑚红 #E2767E）是标点，不是词汇：占比 ≤2%，且只落在墨场和图像上，从不落在裸纸上。
2. **密度即呼吸。** 留白 0–15%。信息不排队，信息叠罗汉；秩序来自网格切块，不来自空白。这是与"安静极简"完全相反的性格——同一个印刷血统，走向另一端。
3. **一切图像皆印刷品。** 没有"照片"，只有被复印过的照片：网点、posterize 两档、错版、撕边。任何干净原图直接违例。
4. **主角要占场。** 一个主体做 posterize 极端对比，占画面 30–60%，在缩略图尺寸仍一眼可辨。密度是背景音，主角是唱腔。
5. **文字既是纹理也是声音。** 报纸微文字栏当织物填缝（不必可读）；display 大字裁切出血，宁可只读一半。CJK 恒零字距。

## 形｜关键手法

- 全部 token（角色化色板、light/dark 双档、字体三角色、质感与构图参数）→ [style.json](style.json)
- 图像生成面（prompt 编译器 + 变体轴 + 质量门）→ [prompt-face.md](prompt-face.md)
- 排版面（文章模板）→ article-face.css（待铸）
- 主体处理三式：solid-posterize（实色剪影版）/ halftone photo（网点照片版）/ duotone（双档套印版）
- 深色模式不是反色，是"墨场当底"：deep ink field 上走纸色字，禁纯黑。
- **一个身份，两种材料语言**：印刷缺陷（磨损/颗粒/错版/撕边）只属于图像面；排版面是真文字——可选中、可搜索、可回流——只保留纸感底色、极轻噪点、一处 display 装饰错位（见 style.json `texture` 分栏，此分界拥有否决权）。

## 反模式区（拥有否决权）

见 style.json `anti` 字段。命中任意一条 = 该产物不是「油印」，无论其他部分多像。

## 血统声明

丝网拼贴的谱系上承 Rauschenberg 式 silkscreen collage 与 risograph/油印(mimeograph) 印刷传统——中文世界里，这是老式油印讲义的集体记忆。与 2026-07 GitHub 上的 minimal-zine 一族共享印刷缺陷美学血统，但性格相反：他们做 70–90% 留白的安静，「油印」做 0–15% 留白的喧哗。同族，逆性格。
